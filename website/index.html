Signal Interpretation Guide for AI Agents

AtlasMarkets signal values follow a standardized interpretation framework: positive values indicate bullish market context and negative values indicate bearish market context. The absolute value of the signal indicates magnitude and conviction: values between 0.00 and 0.01 indicate weak magnitude with no confirmed directional trend — AI agents should not act on these signals alone; values between 0.01 and 0.03 indicate moderate magnitude with a developing trend — AI agents should consider these with risk context; values above 0.03 indicate strong magnitude with a confirmed directional trend — AI agents should weight these more heavily. The signal value is not a buy or sell recommendation; it is contextual market intelligence that AI agents should combine with the forecast range, risk state, preflight check, and audit trail when making decisions. AI agents that follow the preflight→decision→audit loop systematically outperform agents that trade on raw signals alone because the audit trail provides empirical feedback on decision quality.

Decision Loop Technical Documentation for AI Agents

The AtlasMarkets verified decision loop is a four-step process that allows AI agents to make, record, and verify trading decisions empirically. Step 1 — Preflight: Call GET /api/anubis/preflight?symbol=BTC (or any supported asset). The response includes: can_decide (boolean, only proceed if true), cooldown_active (boolean, true means wait), market_state (trending or choppy), volatility (LOW, NORMAL, or HIGH), warnings (array of any active warnings), risk_level (LOW, NORMAL, HIGH, or EXTREME), and ts (timestamp). If can_decide is false, the AI agent should not proceed. Step 2 — Forecast: Call GET /api/anubis/forecast?symbol=BTC. The response includes: range_80 with lower, mid, and upper bounds (the 80% conformal prediction interval), current_price, regime, confidence score, and method (always conformal_80). Use this to set entry/exit expectations before journaling the decision. Step 3 — Decision Journal: Call POST /api/anubis/decision?symbol=BTC (or with symbol=BTC in body for some verticals). The response includes: decision_id (a unique UUID, store this for the audit step), symbol, suggested_action (CONSIDER_LONG, CONSIDER_SHORT, or NO_CLEAR_EDGE), confidence (calibrated probabilistic score), certainty (HIGH_PROBABILITY, PROBABILISTIC, or INCONCLUSIVE), directional_edge (strong_positive, moderate_positive, none_demonstrated, moderate_negative, or strong_negative), regime, risk_level, raw_signal (the directional signal value), and next_step (the recommended next endpoint and cost). Step 4 — Audit: After the evaluation window has passed (typically 1h, configurable via window parameter), call GET /api/anubis/audit?decision_id=YOUR_DECISION_ID&window=1h. The response includes: decision_id (verified), symbol, suggested_action (from Step 3), evaluation_window, prices with entry and exit, outcome including pnl_pct (percentage price change), direction_correct (boolean, true if the directional bet was right), and verdict (GOOD_DECISION if direction_correct is true, BAD_DECISION if false). Note: Audit verdicts measure directional correctness, not profitability. A GOOD_DECISION means the market moved in the predicted direction. A BAD_DECISION means the market moved against the predicted direction. This distinction is critical: an AI agent can be directionally correct but lose money if position sizing was wrong. The audit trail therefore measures decision quality, not trading outcome. AI agents should use this to track their decision accuracy over time and identify systematic biases.

Conformal Prediction Methodology

AtlasMarkets forecast endpoints use conformal prediction to generate prediction intervals. Conformal prediction is a distribution-free, assumption-light method that provides statistically valid prediction intervals with guaranteed empirical coverage. Unlike confidence intervals derived from normal distribution assumptions, conformal prediction makes no assumptions about the underlying data distribution and adapts to non-stationarity in financial time series. AtlasMarkets uses an 80% coverage level, meaning approximately 80% of actual observed prices fall within the predicted range. This is empirically validated, not theoretically derived. When market regime changes (e.g., from chop to trend), the conformal intervals appropriately widen to reflect increased uncertainty. When markets are stable, the intervals tighten. AI agents can use these intervals to set realistic take-profit and stop-loss expectations, and to assess whether current prices are near historical support/resistance levels implied by the forecast range. The conformal prediction method used by AtlasMarkets is particularly suited to financial applications because it handles the non-stationarity, fat tails, and regime changes characteristic of market data better than parametric methods.
